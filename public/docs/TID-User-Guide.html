1 · Getting started

1 Open the app in any modern browser

Browse to the URL where TID is hosted. The welcome screen has a Sign in / Create account toggle.

2 Use a demo account or create your own

  • demo · Demo@123 — standard user with seed data
  • admin · Admin@123 — admin (sees the Admin Console)

Or click Create account, supply email + 10-digit phone + password (8+ chars with letters and numbers), then sign in.

2 · Tour of the workspace

The sidebar lists every module in this order: Goals · Tasks · Notes · Calendar · Investments, plus Admin Console if you're an admin. Each row shows a live count.

The collapse handle on the seam shrinks the sidebar to icons only. The AI Co-pilot orb floats in the bottom-right corner.

3 · Goals

1 Open Goals and click + New goal

2 Fill in the editor

  • Title, Description
  • Category — Health / Learning / Finance / Career / Personal / Habit
  • Target / Current / Unit — e.g. 300000 / 0 / ₹
  • Start & Due dates
  • Status — In progress / Completed / Paused
  • Milestones — type label, press +, repeat

3 Track progress

The + / - buttons bump current value. Click any milestone to toggle done. The ring auto-completes the goal when target is reached.

4 · Tasks

1 Click Add Task

Subject, description, priority (Low / Medium / High), start & end dates, reminder, status, and optional subtasks.

2 Quick-create from the AI

task: review portfolio !high @tomorrow

Modifiers: !high, !medium, !low · @today, @tomorrow, @YYYY-MM-DD.

3 View / edit / delete

Eye / pencil / trash icons in each row. Trash always shows a confirmation dialog.

5 · Notes

1 Click + New note

Title, body, comma-separated tags, color swatch, pin toggle.

2 Pin to keep it on top

Hover any card and click the thumbtack. Pinned notes get their own section.

3 Quick-create from the AI

note: Title | body text

The | splits title from body. Either side can be empty.

6 · Calendar

Month view with task chips on each day. Click a day to open a side panel; click any chip to drill into the task. The + on the calendar toolbar adds a task pre-filled to that day.

7 · Investments

1 Click + Add Investment

Name, type (Stock / Mutual Fund / FD / Bond / Real Estate / Crypto / Other), amount, current value, dates, risk, status, notes.

2 Read the dashboard

Total invested, current value, gain / loss, allocation pie chart, performance bars.

8 · AI Co-pilot

1 Open the orb in the bottom-right

2 Tap the sun icon for a daily briefing

Single composed message across tasks, goals, investments, and your streak.

3 Quick-create commands

task: review portfolio !high @tomorrow
note: Title | body text
goal: Save for laptop target 80000 ₹

4 Suggestions and snooze

Each card has a CTA button (Mark done / Bump +1 / View) and a bed icon to snooze it until tomorrow.

5 Settings (gear icon)

Auto-scan toggle, interval (15/30/60 min), Daily briefing toggle, and a quick-create cheat-sheet.

9 · Theme

Toggle Light / Dark from the sidebar's Account section (or the mobile topbar). Choice persists across sessions.

10 · Admin tools

1 User directory

Search, Promote / Demote, Remove (cascades through tasks, investments, notes, goals).

2 Reset data picker

  • Wipe a user's data — pick a user, clear their data, leave login intact
  • Reset everything — type RESET to confirm, ends session

11 · FAQ

Where is my data stored? Locally, in your browser's localStorage, AES-256-GCM encrypted.

Will it sync across devices? No — TID is frontend-only.

Are passwords secure? PBKDF2-SHA-256, 200,000 iterations, per-user salt.

Will clearing my browser cache delete my data? Yes. Be sure before doing that.
