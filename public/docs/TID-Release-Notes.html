TID v2.0.0 Goals · Notes · Co-pilot

Major release. New modules, security stack, and a redesigned AI Co-pilot.

Highlights

  • Brand-new Goals module — progress rings, milestones, six color tones
  • Brand-new Notes module — sticky-note board, color tags, pin-to-top
  • AI Co-pilot rebuilt for multi-domain awareness, daily briefing, productivity streak, quick-create commands, snooze
  • World-class confirm dialog replaces every native popup
  • PASETO v3.local sessions, AES-256-GCM encrypted storage, PBKDF2 password hashing, login throttling
  • Light-mode polish; world-class responsive layout; new global button system
  • Help section with downloadable User Guide

What's new

Goals

  • Six categories with unique color tones (Health, Learning, Finance, Career, Personal, Habit)
  • Animated SVG progress ring per goal
  • Milestones list with click-to-toggle done/undone
  • Quick + / - bump buttons on every card
  • Auto-completes when target is reached
  • Status chips: In progress (pulsing dot) / Completed / Paused
  • Due-date awareness: "12 days left" / "3 days overdue" / "Done Mar 14"
  • Editor with milestone manager, date pickers, status selector

Notes

  • Seven-color sticky-note palette
  • Pinned section rendered separately
  • Hover-revealed pin / delete actions
  • Search across title, body, and tags + color filter
  • KPI strip showing total notes, pinned count, unique tag count
  • Editor modal with title, body, tags, color swatches, pin toggle

AI Co-pilot

  • Multi-domain scan: tasks, goals, investments, notes
  • Suggestion types: overdue, due today, high-priority open, stalled WIP, goals at risk, goals close, investments maturing, big losers
  • Daily briefing — once-a-day summary across all domains
  • Quick-create: task: ..., note: ..., goal: ... target N
  • Snooze a suggestion until tomorrow (bed icon)
  • Productivity streak counter with flame chip
  • Bump-goal action — + increments goal progress
  • Time-of-day greeting + first-name personalization
  • Small-talk recognition
  • Memory-leak safe; visibility-paused polling

Confirm dialog

  • Tone presets: danger / warning / info / success
  • Optional "type to confirm" mode
  • Eyebrow + title + body + optional bullet details
  • Bottom-sheet behavior on mobile
  • Esc dismisses, Enter confirms, backdrop click cancels
  • Auto-focus Cancel for danger tones

Admin reset experience

  • Top-right "Reset data…" opens a scope picker
  • Wipe a user's data — in-modal user picker; login credentials stay intact
  • Reset everything — type-to-confirm, ends session
  • User remove cascades through tasks, investments, notes, goals

Security stack

  • PASETO v3.local authenticated tokens (HMAC-SHA-384 verify-before-decrypt)
  • AES-256-GCM encrypted localStorage with key bound as AAD
  • PBKDF2-SHA-256 password hashing (200,000 iterations, per-user salt)
  • Login throttling with exponential backoff (3 fails = 10s → 15min cap)
  • HKDF-SHA-384 subkey derivation per PASETO spec
  • Constant-time tag comparison
  • Production builds: sourceMap: false, namedChunks: false
  • Defense-in-depth meta tags: X-Content-Type-Options, Referrer-Policy, Permissions-Policy
  • 30-minute session token TTL with auto-logout
Honest note: in a frontend-only app, anyone with full device access can still read the device key from localStorage. Real-world auth requires a backend.

UI / UX polish

  • Global button system: primary / ghost / cancel / danger / row-btn / icon-btn
  • Light-mode rework — deeper shadows, gradient surfaces, plasma-bg recoloring, frosted mobile topbar
  • Login page redesigned with gold-icon feature cards
  • Plasma background animation across the app shell (login excluded)
  • Sidebar order: Goals → Tasks → Notes → Calendar → Investments → Admin Console
  • Live badge counts for each module

Help section (new)

  • Reachable from the Account section in the sidebar
  • Shows app version, release name, copyright
  • Step-by-step User Guide (HTML, printable, "Save as PDF" friendly)
  • This Release Notes document

Breaking changes

  • Storage seed key bumped from tid.seeded.v2 → tid.seeded.v3 (notes/goals backfill is non-destructive)
  • Auth tokens are now PASETO v3.local — older tokens are ignored on boot, prompting fresh login

Removed

  • Native browser confirm() / alert() (replaced everywhere with the custom dialog)
  • Bare <ngx-spinner> markup in components (centralized via LoaderService)
  • Scan-now icon from the AI Co-pilot panel header (use the chip below instead)

Known limitations

  • Frontend-only — no server-side enforcement, no multi-device sync
  • Encrypted storage protects against casual inspection and tampering, not a determined operator
  • CSP via <meta> was removed (it broke Font Awesome webfonts in dev). Reference policy is documented in index.html for HTTP-header use at deploy time

Migration

No user action required. On first launch after upgrade:

  • Notes and Goals seeded with demo content (only on the demo account)
  • Existing tokens silently rejected; users return to the login screen
  • All existing tasks and investments remain intact and migrate to encrypted storage
